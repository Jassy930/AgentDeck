# 桌面端视觉打磨（三轮自检）

目标：把 GPUI 桌面端主页、会话页、机器页的视觉品质提到设计奖项（Awwwards / Webby / FWA）评审能认可的水准。桌面原生应用不追求网页式炫技，评审关注的是层级、节奏、材质、状态表达和细节一致性。

约束：

- 配色只用 `theme_tokens.rs`（设计系统生成物，禁止手改）里的 token，新色调一律在代码里用 `opacity` / `lighten` / `darken` 派生。
- 锁深色；侧栏宽度和全高结构沿用 Codex Desktop 对齐。
- 只改渲染层，不碰数据流和交互语义。

## 评分表（每项 1–5 分）

| 维度 | 含义 |
| --- | --- |
| 层级 | 一眼能分清主次：标题、主内容、辅助信息 |
| 节奏 | 间距、对齐、栅格是否成体系，有无孤儿元素与大片死区 |
| 材质 | 深度、光感、表面层次，是否只是平涂 |
| 状态 | 选中、聚焦、失败、只读等状态是否可读且克制 |
| 细节 | 图标、圆角、字号、截断、边线是否一致 |

## 第一轮

改动：主页卡片改固定列 grid（6 张为 3×2），单卡最大 232px，随主区宽度收窄，机器名过长时省略；卡片换成「图标块 + 机器标签 + agent 名 + 大号会话数」，顶部加品牌色极淡渐变光晕，标题上方加统计胶囊；只读提示改为带状态点的胶囊；会话页用户消息成卡片、不支持内容成虚线框、各消息标签加色点；过程摘要行用 chevron 图标并带悬停底色；头部元信息拆成标签并可截断；兼容性警告条减弱为浅黄底 + 细边；侧栏「新建会话」加图标、分组标题降为 xs、机器数改胶囊；全局聚焦环降到 55% 透明度。

| 页面 | 层级 | 节奏 | 材质 | 状态 | 细节 | 残余问题 |
| --- | --- | --- | --- | --- | --- | --- |

| 会话页 | 4 | 3 | 2 | 3 | 3 | 头部标签需去掉 fps 叠层后复核；记录区上下缘无过渡，底部胶囊压在内容上 |

## 第二轮

改动：机器页标题放大并带台数胶囊；机器卡片改为渐变表面 + 阴影 + 14px 圆角，头部状态改成带光晕圆点的彩色胶囊，daemon 版本改等宽字体，agent 列表上方加分隔线；会话记录区上下缘加 28px 渐隐，列表上下各留同高的滚动内边距，保证到达边界时首尾内容完整显示（含折叠过程组）。复核头部标签（去掉 fps 叠层后）显示正常、不溢出。

## 验证方式

- 目视：每轮用临时环境变量开关让应用自动进入会话页 / 机器页，构建后窗口级截图并按评分表打分；开关已在提交前删除，主页终图用最终代码重拍。
- 门禁：`cargo fmt --check -p agentdeck-desktop`、`cargo test -p agentdeck-desktop`（62 通过）、`--selfcheck`、`./script/build_and_run.sh --verify` 均通过。
- 注意：同 bundle id 的多个 AgentDeck 实例同时运行时，`open` 可能把别的实例带到前台，截图要按进程 PID 选窗口。

## 未做与后续

- 侧栏材质（真毛玻璃）受外接 SDR 屏物理限制，未动。
- 渐变与阴影均为静态绘制，未引入动画；滚动帧率未单独复测（受 macOS 60Hz 滚动事件封顶）。
- 悬停、展开等需要真实输入的交互态未截图验证。
