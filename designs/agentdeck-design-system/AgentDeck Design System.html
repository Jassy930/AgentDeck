AgentDeck 让你在同一处观察、审批并驾驭 Codex 与 Claude Code——流式的思考、命令与文件变更，从桌面延伸到手中。这套设计系统提供一个统一的信息架构，六种设计语言可一键切换。

六种设计语言

点击卡片即可切换
① Codex Desktop

主基调。近黑、极低饱和、暖橙强调，柔和 18pt 大圆角，SF 系统字体。安静、克制、贴近终端。

② Terminal 终端

纯黑、全等宽字体、磷光绿、锐角与微网格。高密度、高对比，像一块开发者控制台。

③ Linear 精密

蓝黑基底、靛紫强调，8pt 锐利圆角、微渐变表面与细高光边。精致的现代产品感。

④ Warm 编辑感

暖纸白亮色主题、锈红强调、衬线标题。为日间与户外阅读而生，也是移动端的一张好牌。

⑤ Notion 文档感

纯白、Notion 蓝、暖灰发丝边、极小圆角。刻意「结构全默认」——只填皮肤即成一套主题，零组件改动。

⑥ macOS 原生

系统蓝、SF 字体、系统灰、标准控件圆角与柔和系统阴影。原生感来自色/字/圆角/材质，而非奇异结构。

所有界面共用一套语义 Token（--surface / --accent / --warn …）。切换主题只是翻转 data-theme，组件代码零改动——这正是跨端与多品牌可持续的关键。

主题与切换 · Theming

多套设计语言如何长期共存、可维护地切换。核心原则：组件从不写 if theme ==，只读一组【可枚举的结构开关】；加一套新主题 = 填值，不改组件。完整契约见 THEMING.md。

三层模型

L1
语义 / 契约层 —— 统一，永不切换

信息架构、区域拓扑、组件契约与状态、内容、交互逻辑、状态语义（running/await/fail/done 的含义）、可访问性、44pt 触控、焦点顺序。

统一
L2
Token 层（皮肤）—— 声明式切换

颜色、字体、圆角、间距刻度、阴影、动效。纯值，安全且无限扩展。tokens.css

切换 · 值
L3
结构 / 语言层 —— 可枚举开关切换

词缀、图标策略、状态形状、表面质感、composer 形态、大小写、纹理、可选插槽。interface.css(引擎) + languages.css(赋值)

切换 · 开关

接缝：哪些统一 / 哪些切换

「是什么」统一 · 「长什么样」切换

统一（永不随主题变）

  • 信息架构与界面清单
  • 区域拓扑：侧栏 + 内容 + composer + 环境面板 + 轮次导航
  • 组件契约与状态机
  • 状态语义（等待审批 = 等待审批）
  • 交互逻辑、键盘模型
  • 可访问性、≥44pt 触控、焦点顺序、reduced-motion 回退
  • 内容与文案

切换（主题通过接口填）

  • 颜色 / 字体 / 圆角 / 间距 / 阴影 / 动效（L2）
  • 词缀：$  #  >  []  ├─  —
  • 状态渲染：圆点 / 方块 / pill
  • 图标策略：line / glyph / 隐藏
  • 表面质感：浮起 / 平面 / 规线 / TUI 盒
  • composer 形态：卡片 / 命令行 / 编辑器
  • 大小写、密度、背景纹理
  • 可选插槽：命令栏 / 块光标 / byline

加一套新主题 = 填值，不改组件

/* tokens.css：声明皮肤 */
[data-theme="notion"] {
  color-scheme: light;
  --bg:#fff; --surface:#f7f6f3; --text:#37352f; --accent:#2383e2;
  --radius-md:6px; --font-display:"…";
}
/* languages.css：从开关菜单里选（这套走极简，几乎全默认）*/
[data-theme="notion"] {
  --k-status-radius: 3px;      /* 圆角小方块 */
  --k-label-variant: normal;
}
// 完成。不改任何组件，不写一条 [data-theme] .someComponent 覆盖。
治理原则：开关清单封闭；组件禁止写 if theme ==；空值零副作用；语义永远留在 L1。该契约可平移到 AppKit 的 Theme 值类型（token + 结构枚举），呼应 CapabilityRouter 无分支哲学。详见 THEMING.md。
